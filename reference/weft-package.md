# weft: Computed Values and Checks for Quarto and R Markdown Prose

Lets a manuscript's prose carry computed values, and wording that
depends on them, and adds deterministic checks for computational
manuscripts. Every construct is markdown that 'knitr', 'Pandoc' and
'Quarto' already accept.
